# Lzzy Tech

Premium Dark Tech customer-facing e-commerce frontend for computer peripherals and accessories in Pakistan.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Lucide React
- Zustand cart state with persistence
- React Hook Form + Zod checkout validation

## Run
```bash
npm install
npm run dev
```

## Scope
Customer storefront only. No admin, supplier, warehouse, courier, ERP, payment gateway, or PC component catalogue.
